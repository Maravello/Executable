# Executable – Application PC (bientôt mobile)

## 🧰 Description

**Executable** est une application desktop qui offre plusieurs fonctionnalités avancées :  

- Lecture de texte  
- Modification de texte  
- Récupération de données via UDP  
- Et bien d’autres fonctionnalités prévues  

Le projet est en cours d’évolution et une **version mobile** sera bientôt disponible grâce à **Xamarin**, permettant de proposer une expérience similaire sur smartphones et tablettes.

## 🔗 Lien vers le projet

Le code source complet est disponible sur GitHub :  
[https://github.com/Maravello/Executable](https://github.com/Maravello/Executable)

## ⚙️ Fonctionnalités actuelles

- Lire et afficher du texte  
- Modifier du texte en temps réel  
- Recevoir et traiter des données via UDP
